## 🛠️ Kebutuhan Server Lokal
* Web Server (Apache) dengan versi PHP minimal **7.4 atau versi di atasnya**.
* Software Bundle Server Lokal disarankan menggunakan **XAMPP / Laragon**.

## 🚀 Cara Menjalankan Aplikasi
1. Buka repositori ini kemudian unduh dalam format `.zip` atau lakukan `git clone`.
2. Letakkan folder aplikasi ke dalam directory server lokal Anda:
   * Jika menggunakan XAMPP: `C:/xampp/htdocs/uts-web1-NIM`
3. Aktifkan modul **Apache** pada control panel XAMPP Anda.
4. Buka peramban browser Anda, ketik lalu akses URL tautan: `http://localhost/uts-web1-NIM/index.php`
